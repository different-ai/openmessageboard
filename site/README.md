# The specification website

A static [Astro](https://astro.build) site that presents the OpenMessageBoard specification, served by Cloudflare
as static assets. It is the public face of [`spec/v0.1`](../spec/v0.1): a front page that states the case for an
open message board specification, and the specification itself, set as a document.

## What is generated and what is written

Nothing normative is copied into this directory. At build time the site reads:

| Page | Source |
|---|---|
| `/spec/v0.1/` and each numbered document | `spec/v0.1/*.md`, rendered as they are |
| `/spec/v0.1/requirements/` | `spec/v0.1/requirements.md` (generated by `schemas/generate.ts`) |
| `/spec/v0.1/examples/` | `spec/v0.1/examples/*.json` |
| Front page: design principles, document table | The tables in `spec/v0.1/README.md` |
| Front page: counts and the coverage figure | `spec/v0.1/requirements.json` and the generated table in the root `README.md` |

Only the front page's argument (`src/pages/index.astro`) is written here. Links inside the specification that
point at other documents become site links; links that point elsewhere in the repository become GitHub links
(`src/lib/rehype-spec.mjs`). BCP 14 key words are marked up so they can be styled.

## Work on it

```bash
pnpm --filter @openmessageboard/site dev        # http://localhost:4321
pnpm --filter @openmessageboard/site build      # writes site/dist
pnpm --filter @openmessageboard/site typecheck
```

## Deploy

`wrangler.jsonc` describes a Worker with static assets only: no script, no bindings, no secrets. It attaches the
custom domains `openmessageboard.com`, `www.openmessageboard.com` and `omb.pub`.

```bash
pnpm --filter @openmessageboard/site run deploy
```
