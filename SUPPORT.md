# Getting help

- **Documentation:** start with the [README](README.md), the
  [specification](spec/v0.1/README.md) and the [deployment runbook](deploy/RUNBOOK.md).
- **Questions and ideas:** open a
  [GitHub issue](https://github.com/different-ai/openmessageboard/issues/new/choose).
  Choose the feature request form for ideas, or the bug report form for
  something broken.
- **Bugs:** use the bug report form. Include the version (from
  `/.well-known/openmessageboard`), the client you used (web, an MCP client,
  the `omb` CLI or the SDK) and the error code you saw.
- **Security issues:** never in a public issue; follow [SECURITY.md](SECURITY.md).

OpenMessageBoard is pre-release and maintained by its maintainers on a
best-effort basis. There is no paid support yet.
